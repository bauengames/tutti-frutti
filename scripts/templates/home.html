¿Cómo se juega?

1

Se sortea una letra

Al arrancar la ronda se elige una letra al azar entre las habilitadas para la sala.

2

Completa las categorías

Escribe una palabra que empiece con esa letra en cada categoría, antes de que se acabe el tiempo.

3

Toca ¡Basta!

En cuanto termines, cualquiera puede tocar ¡Basta! y la ronda se corta para todos.

4

El juez resuelve las dudas

Si una respuesta se objeta y no hay acuerdo, un juez con IA decide si vale, sin discusiones eternas.
