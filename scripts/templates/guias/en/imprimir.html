What's on each sheet

Classic sheet

The eight usual categories: Name, Last name, Country, City, Animal, Food, Color and Object. There's a column for the letter of each round and another for points, with twelve rows for a long game.

Kids sheet

Six easy categories (Name, Animal, Fruit, Color, Toy and Thing at home) and bigger boxes, made for kids who are still learning to write. It has fewer rows so the game doesn't drag on.

Blank sheet

The category headers are empty so you can write whatever you want. It's perfect for themed games (movies, sports, music) or for class with categories from a school subject. If you need ideas, there are more than 90 Stop game categories grouped by theme and difficulty.

How to use the sheet

  1. Print one sheet per player. If you'll play often, laminate it and use a dry-erase marker.
  2. One person silently runs through the alphabet and someone else says "stop" at any moment. The letter they stopped on is the letter for the round. Write it in the first column.
  3. Everyone fills in each category with a word starting with that letter. The first player to finish shouts "Stop!" and everyone else puts their pen down.
  4. Read the answers out loud and write down the points in the last column.

For scoring, the most common rule is the same one the online game uses: 10 points for an answer nobody else wrote, 5 if someone wrote the same word, 20 if you were the only person who filled in that category, and 0 if it's empty or invalid. All the details are in the Stop game rules.

Paper or online: when to use each

The paper sheet is perfect for a dinner table, a long road trip or a classroom without devices. The online version handles the parts that cause arguments on paper: it draws the letter fairly, ends the round for everyone at the same time, adds up the score for you and, when someone challenges a word, an AI judge decides whether it counts. It also lets you play remotely, as explained in the guide to playing Stop on a video call.
